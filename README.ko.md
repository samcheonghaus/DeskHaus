# DeskHaus (데스크하우스)

**파일 하나. 도구 하나. 매일 하는 사무 작업 전부.**

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

[**▶ 바로 써보기**](https://samcheonghaus.github.io/DeskHaus/) · [English README](./README.md)

DeskHaus는 **HTML 파일 하나**로 브라우저에서 바로 실행되는 가벼운 사무 도구 모음입니다. 설치도, 서버도, 계정도 필요 없습니다. 문서 작성, 이미지 편집, 스프레드시트 계산, PDF 처리, 프레젠테이션 제작, 3D 캐드 도면 보기까지 한곳에서 해결합니다. 모든 작업은 내 컴퓨터 안에서만 이루어집니다.

## 시작하기

1. `index.html` 파일을 내려받습니다
2. 최신 브라우저(크롬, 엣지, 파이어폭스, 사파리)로 엽니다
3. 끝입니다.

오른쪽 위 **❓ 설명서** 버튼을 누르면 언제든 사용 안내를 볼 수 있습니다. 별도의 브라우저 탭으로 열리므로 작업 화면을 가리지 않으며, 설명서 안에서 한국어/영어 전환과 PDF 저장이 가능합니다.

> 처음 사용할 때는 인터넷 연결이 필요합니다 — 계산 엔진, PDF 도구, 3D 판독기 등의 라이브러리를 공개 CDN에서 불러오며, 이후에는 브라우저가 캐시해 둡니다.

## 기능

### 📝 글 — 문서와 레터헤드
- A4 페이지 위에서 서식 있는 글쓰기, 로고·이름·연락처가 들어간 나만의 레터헤드
- 표와 이미지 삽입, 이미지를 더블클릭하면 그림 모드에서 편집한 뒤 다시 문서에 적용
- `.docx`, `.html`, `.txt`, `.hwpx` 열기 — HTML, Word(.docx), 텍스트로 저장

### 🖼 그림 — 레이어 기반 편집기
- 레이어 이동·크기 조절·순서 변경·숨기기·이름 바꾸기
- 도형과 텍스트 그리기, 캔버스 크기와 배경색 설정
- PDF 페이지나 문서 속 이미지를 가져와 편집하고 다시 돌려보내기

### 📊 표 — 엑셀 기본기를 제대로 갖춘 스프레드시트
- **넉넉한 작업 영역** — 처음부터 200행 × 40열(A~AN), 끝까지 스크롤하면 **자동으로 계속 확장**
- **수식**: HyperFormula 엔진으로 `=A1+B1`, `=SUM(A1:A10)`, `=AVERAGE(...)` 등 수백 가지 함수 지원
- **범위 선택**: 드래그, Shift+클릭, Shift+화살표, 머리글 클릭으로 행·열 전체 선택, Ctrl+A
- **선택 즉시 통계** — 범위를 선택하면 합계·평균·개수가 바로 표시 (엑셀 상태 표시줄처럼)
- **Σ 자동 합계** — 클릭 한 번으로 선택 범위에 맞는 `=SUM()` 자동 삽입
- **복사/잘라내기/붙여넣기** (Ctrl+C/X/V) — 상대 참조 자동 이동, 실제 엑셀과 양방향 클립보드 호환
- **자동 채우기 핸들** — 선택 모서리를 끌면 `1, 2`가 `3, 4, 5`로, 수식은 참조가 따라 이동
- **실행 취소/다시 실행** (Ctrl+Z / Ctrl+Y)
- **찾기/바꾸기** (Ctrl+F / Ctrl+H) — 표를 가리지 않는 작은 창에서
- **셀 병합** — 버튼 하나로 병합/해제 토글, 엑셀로 저장해도 병합 유지
- **피벗 테이블** — 행/열/값 필드와 계산 방식(합계·개수·평균·최소·최대)을 골라 총합계까지 한 번에
- 행·열 삽입/삭제 시 수식 참조 자동 조정, 열 너비 조절, 머리글을 알아보는 정렬
- 서식은 선택 범위 전체에 즉시 적용: 굵게·기울임·밑줄, 정렬, 글자색·배경색(색을 고르는 순간 바로 칠해짐), 천 단위 쉼표, %, 소수 자릿수
- `.xlsx` / `.csv` 열기·저장(수식 보존), 표를 문서로 바로 보내기

### 📄 PDF
- PDF 보기·확대·페이지 이동
- PDF 이어붙이기, 페이지 삭제, 한 페이지만 저장 또는 전체 저장
- 페이지를 그림 모드로 가져와 표시하거나 PNG로 내보내기

### 📽 PPT
- 16:9 슬라이드에 텍스트·도형·이미지, 드래그로 이동·크기 조절·바로 수정
- 발표자 노트, 슬라이드쇼 모드, `.pptx` 열기/저장

### 🧊 3D — STEP 뷰어와 도면 변환
- `.step` / `.stp` 캐드 파일 열기 (오픈캐스케이드 WebAssembly로 판독)
- 마우스 드래그 회전, 휠 확대·축소, 오른쪽 버튼 드래그 이동 / 정면·윗면·우측·입체 보기 원클릭 / 면·선(와이어프레임) 전환
- **PDF 도면 저장** — 정면·윗면·우측면·등각 4면도와 제목란이 들어간 A4 한 장짜리 도면
- **DXF 저장 (캐드용)** — AutoCAD 등 캐드에서 바로 열리는 DXF(AC1009)로 저장한 뒤, 캐드에서 **DWG로 다른 이름 저장** 한 번이면 됩니다
- DWG는 오토데스크의 비공개 형식이라 직접 쓰지 않습니다 — DXF를 거치는 것이 가장 확실한 경로입니다

*STEP 판독 모듈(약 10MB WebAssembly)은 처음 사용할 때 한 번 내려받고 이후에는 캐시됩니다.*

## 단축키 (표 모드)

| 단축키 | 동작 |
|---|---|
| 화살표 / Enter / Tab | 셀 이동 |
| Shift + 화살표 / 클릭 | 선택 확장 |
| Ctrl + 화살표 | 데이터 끝으로 점프 |
| Ctrl + A | 전체 선택 |
| F2 또는 더블클릭 | 셀 편집 |
| Ctrl + C / X / V | 복사 / 잘라내기 / 붙여넣기 |
| Ctrl + Z / Y | 실행 취소 / 다시 실행 |
| Ctrl + D / R | 아래로 / 오른쪽으로 채우기 |
| Ctrl + B / I / U | 굵게 / 기울임 / 밑줄 |
| Ctrl + F / H | 찾기 / 바꾸기 |
| Delete | 선택 범위 지우기 |

수식 입력 중(`=`로 시작)에 다른 셀을 클릭하거나 드래그하면 `A1`, `A1:B5` 같은 참조가 자동으로 들어갑니다.

## 언어

한국어와 English를 완전히 지원합니다 — 상단의 언어 버튼으로 언제든 전환하세요.

## 기술

단일 HTML 파일 + 순수 JavaScript. 라이브러리는 CDN에서 불러옵니다:

| 라이브러리 | 용도 |
|---|---|
| [HyperFormula](https://hyperformula.handsontable.com/) | 스프레드시트 수식 엔진 |
| [SheetJS (xlsx)](https://sheetjs.com/) | 엑셀/CSV 읽기·쓰기 |
| [pdf.js](https://mozilla.github.io/pdf.js/) / [pdf-lib](https://pdf-lib.js.org/) | PDF 표시·편집 |
| [mammoth](https://github.com/mwilliamson/mammoth.js) / [docx](https://docx.js.org/) | Word 가져오기·내보내기 |
| [PptxGenJS](https://gitbrent.github.io/PptxGenJS/) / JSZip | PPT 내보내기·가져오기 |
| [Three.js](https://threejs.org/) | 3D 렌더링 |
| [occt-import-js](https://github.com/kovacsv/occt-import-js) | STEP 파일 판독 (오픈캐스케이드 WASM) |

## 개인정보
